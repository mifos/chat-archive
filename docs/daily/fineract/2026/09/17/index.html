In the "dev" branch in Apache Fineract there is a major non-functional upgrade of the platform dependencies, it is targeting for being included in the next stable release. So then if you are developing using the "dev" branch, make sure to pull the latest changes and make the proper configuration on your development environment,
Pull Request: FINERACT-2621: Upgrade dependencies to Spring Boot 4.1

JIRA: FINERACT-2621
Spring Boot Migration Guide: github.com/spring-projects/spring-boot/wiki/Spring-Boot-4.0-Migration-Guide
This upgrade keeps Fineract on a supported, modern stack and positions the project for continued improvements in security, performance and maintainability.
Thank you to the contributors who made this possible, especially to Avinash Vijayvargiya, Aleks Adam Saghy, Aman Mittal, Aleksandar Vidakovic.
